# sockets-redes

Práctica universitaria de Redes I en C: futuro miniservicio web cliente-servidor con sockets de Berkeley, compatible con TCP y UDP.

El desarrollo se realizará en Windows con VS Code y Codex. La compilación y las pruebas finales se realizarán bajo Linux Debian en el servidor de la universidad, nogal.

## Estructura

- `ejemplos/`: archivos originales de referencia: `servidor.c`, `clientcp.c`, `clientudp.c` y `Makefile`. Se conservan sin modificar.
- `docs/`: documentación y PDF del enunciado y material de apoyo.
- `src/`: futuro código del cliente y del servidor.
- `www/`: futuras páginas HTML del servicio.
- `pruebas/`: futuros ficheros de órdenes y pruebas.
- `.gitignore`: exclusiones de ejecutables, objetos y logs generados.

Por ahora solo se prepara la estructura; el cliente y el servidor todavía no están implementados. Los archivos `.gitkeep` permiten conservar en Git las carpetas vacías.
